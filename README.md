# Distance Between Two Points Calculator

## Description

This purpose of this program is to calculate the distance between two points on a Cartesian Coordinate Plane. Made originally for the Formative Assessment 4, Computer Science 2.

## How to Run

1. Open the file in an IDE that can run a .py file, (eg. VSCode, Replit, Google Colab, etc.)
2. Run the program using the selected IDE.
3. Give what is asked.
 - X represents the abscissa.
 - Y represents the ordinate.
 - 1 represents the first point.
 - 2 represents the second point.
4. View the distance displayed on the screen in order to get your answer.

## Input Needed

- point_x1
- point_x2
- point_y1
- point_y2

## Sample Output

Enter point_x1 value: 1
Enter point_y1 value: 2
Enter point_x2 value: 3
Enter point_y2 value: 4
x1 Entered: 1.0
y1 Entered: 2.0
x2 Entered: 3.0
y2 Entered: 4.0
The distance between the two points is: 2.83
